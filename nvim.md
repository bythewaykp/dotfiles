## COMMAND MODE

:w - save
:wq - save and quit
:q! - quit without saving
:%s/<toreplace>/<tobereplaced>
:2,3s/<toreplace>/<tobereplaced>

u - undo
Ctrl r - redo

## VISUAL MODE (v)

y - copy
d - cut
p - paste
w - next work beginning 
b - previous word beginning
e - next word end
0 - beginning of line
$ - end of line
{ - beginning of newline
} - end of newline
